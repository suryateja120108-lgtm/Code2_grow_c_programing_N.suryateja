This C program simulates a canteen billing system that calculates individual customer bills and the total revenue for all customers.Summary of FunctionalityInput for total customers:
The program begins by asking for the number of customers.Loop for each customer (for loop):
For every customer:The user specifies how many items they purchased.For each item, the program asks for:The item code (1–5, representing menu items).The quantity purchased.Based on the code, the program assigns a price:1  Sandwich (80)2  Burger (120)3  Pizza Slice (150)4  Coffee (60)5  Juice (50)It then calculates the cost for each item (price * quantity) and adds it to the customer’s total.
